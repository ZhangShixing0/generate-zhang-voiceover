# Math Pronunciation

Resolve notation as spoken Chinese in the visible final script before synthesis. Keep the original formula in a visual when needed; never maintain a hidden alternate narration.

## Common Forms

| Written form | Spoken form |
|---|---|
| `x -> 0` | 当 x 趋近于零时 |
| `lim f(x)` | f x 的极限 |
| `x^2` | x 的平方 |
| `x^n` | x 的 n 次方 |
| `1/2` | 二分之一 |
| `dy/dx` | y 对 x 的导数 |
| `f'(x)` | f x 的一阶导数 |
| `f''(x)` | f x 的二阶导数 |
| `∫` | 积分 |
| `∫_0^1` | 从零到一的定积分 |
| `sin x` | 正弦 x |
| `cos x` | 余弦 x |
| `ln x` | x 的自然对数 |
| `e^x` | e 的 x 次方 |

## Rules

- Expand symbols into phrases a teacher would naturally say.
- Add explanatory sentences only while writing or when the user authorizes revising the visible script.
- Separate the problem, method, key step, and conclusion with full stops.
- Resolve ambiguous Latin letters explicitly; do not silently substitute a word with different mathematical meaning.
- Spell years and question numbers in the intended spoken form.
- Use complete semantic blocks; character counts are diagnostic, not a reason to cut approved wording.
